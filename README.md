# Joydev Mandal | Portfolio (Vue 3)

Vue 3 + Vite + plain JavaScript + plain CSS. All text is in JSON files in `src/data/`.

## Run locally (Windows PowerShell)

1. Install Node.js LTS from https://nodejs.org (check with `node -v`).
2. Open PowerShell in this folder, then:
   ```
   npm install
   npm run dev
   ```
3. Open http://localhost:5173

## Build
```
npm run build
npm run preview
```
Production files are in `dist/`.

## Replace placeholders
- `src/data/contact.json`: email, LinkedIn, GitHub
- `src/data/projects.json`: your projects
- `src/data/profile.json`: name, headline, intro, about text
- `src/data/skills.json`, `src/data/education.json`
